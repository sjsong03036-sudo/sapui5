
## SAP 용어

| 용어                      | 의미                                                   |                                                              |
| ----------------------- | ---------------------------------------------------- | ------------------------------------------------------------ |
| **SAP ECC**             | 이전 세대의 대표적인 SAP ERP 제품                               |                                                              |
| **SAP S/4HANA**         | SAP HANA 데이터베이스를 기반으로 하는 ERP 제품                      |                                                              |
| **SAP HANA**            | 데이터를 저장하고 처리하는 데이터베이스                                |                                                              |
| 용어                      | 쉽게 설명하면                                              |                                                              |
| **SAP GUI**             | SAP 시스템에 접속해서 업무를 처리하거나 개발·관리 작업을 하는 대표적인 접속 프로그램    |                                                              |
| **SAP Fiori**           | SAP가 제시하는 사용자 경험과 화면 설계 원칙, 이를 따르는 앱들을 가리키는 말        |                                                              |
| **Fiori Launchpad**     | 여러 업무 앱에 들어가는 시작 화면                                  |                                                              |
| 기술                      | 역할                                                   | 예시                                                           |
| **HTML**                | 웹 화면의 기본 구조                                          | 제목, 입력란, 버튼                                                  |
| **CSS**                 | 화면의 모양과 배치                                           | 색상, 글꼴, 간격                                                   |
| **JavaScript**          | 화면의 동작과 처리                                           | 버튼 클릭, 입력값 검사, 데이터 요청                                        |
| **SAPUI5**              | SAP 업무용 웹 앱을 만들기 위한 UI 프레임워크                         | 표, 검색 조건, 데이터 연결 등을 활용한 화면 개발                                |
| 용어                      | 역할                                                   |                                                              |
| **ABAP**                | SAP에서 업무 로직 등을 개발하는 프로그래밍 언어                         |                                                              |
| **CDS View**            | 여러 데이터를 연결·계산하고 업무 의미를 부여해 조회 모델로 정의하는 기술            |                                                              |
| **OData**               | 웹에서 데이터를 조회·생성·수정·삭제할 수 있도록 하는 표준 기반 프로토콜            |                                                              |
| **SAP Gateway**         | SAP의 데이터를 OData 서비스로 제공하는 데 사용되는 기술                  |                                                              |
| 용어                      | 정리                                                   |                                                              |
| **ABAP Workbench**      | ABAP 프로그램과 관련 개발 객체를 만드는 도구 모음. 단순한 텍스트 편집기보다 범위가 넓음 |                                                              |
| **Web Dynpro ABAP**     | ABAP 환경에서 웹 애플리케이션을 개발하는 UI 기술                       |                                                              |
| **UI Theme Designer**   | 지원되는 SAP 앱의 색상·글꼴 등 테마를 조정하는 도구                      |                                                              |
| **SAP Screen Personas** | 기존 SAP 화면을 단순화하거나 사용자에게 맞게 바꾸는 도구                    |                                                              |
| **RPA**                 | 사람이 반복하는 화면 조작 등의 업무를 자동화하는 기술                       |                                                              |
| 구분                      | 의미                                                   | 예시                                                           |
| **SI**                  | System Integration. 시스템 구축·통합 프로젝트                   | SAP 신규 도입, S/4HANA 전환, 신규 사업 시스템 구축                          |
| **SM**                  | 현업에서 시스템 운영·유지보수 업무를 가리키는 표현                         | 장애 대응, 기능 수정, 정기 작업, 제도 변경 대응                                |
| 용어                      | 뜻                                                    | 특징·쉽게 이해하기                                                   |
| **ECC**                 | ERP Central Component                                | 영업·구매·생산·회계 등을 처리하는 SAP의 기존 세대 ERP. 후속 제품은 **S/4HANA**       |
| **SD**                  | Sales and Distribution                               | 판매·유통 모듈. **판매오더 → 출고 → 청구** 업무 담당                           |
| **SD 로직**               | SD 업무의 처리 규칙                                         | 가격·할인 계산, 출고 조건, 청구 처리 등을 결정하는 규칙이나 코드                       |
| **ABAP**                | SAP에서 사용하는 프로그래밍 언어                                  | SAP 업무 프로그램과 기능 확장 등을 개발                                     |
| **Classic ABAP**        | 전통적인 ABAP 개발 방식                                      | 기존 CBO·리포트·SAP GUI 화면 개발 등에 사용. ECC뿐 아니라 S/4HANA에서도 사용       |
| **CBO**                 | Customer Bolt-On                                     | SAP 표준에 없는 회사별 요구사항을 위해 별도로 개발한 프로그램·기능                      |
| **CDS**                 | Core Data Services                                   | **필요한 데이터를 어떻게 묶어 가져올지 적어둔 조회용 설계도**. 테이블 연결·계산·집계 등을 정의     |
| **T-code**              | Transaction Code                                     | 특정 화면이나 기능을 실행하는 코드. 예: `VA01`은 판매오더 생성                      |
| **`/n`**                | SAP 명령창의 이동 명령                                       | 현재 트랜잭션을 끝내고 다른 트랜잭션 실행. 예: `/nVA03`. “엔코드”가 이것을 뜻했는지는 확인 필요 |
| **SAPUI5**              | 웹 화면 개발 프레임워크                                        | 버튼·검색창·표 등을 이용해 SAP용 웹 화면 개발                                 |
| **UI5**                 | UI5 계열의 통칭                                           | 현업에서는 흔히 **SAPUI5를 줄여 부르는 말**                                |
| **OpenUI5**             | UI5의 오픈소스 버전                                         | SAPUI5와 핵심을 공유하며, 제공 라이브러리에 차이가 있음                           |
| **RFC**                 | Remote Function Call                                 | 외부 시스템에서 **SAP 함수를 호출하고 결과를 받는** 통신 방식                       |
| 이니셜                     | 원래 단어                                                | 의미                                                           |
| **Z / Y**               | 약자 아님                                                | 고객 개발 객체를 나타내는 접두사                                           |
| **R**                   | Report                                               | 조회·리포트                                                       |
| **I**                   | Interface                                            | 시스템 간 연계                                                     |
| **C**                   | Conversion                                           | 데이터 변환·이관                                                    |
| **E**                   | Enhancement                                          | 기능 확장                                                        |
| **F**                   | Form                                                 | 출력 양식                                                        |
| **W**                   | Workflow                                             | 승인·업무 처리 흐름                                                  |

| --- | ----------------------------- | --------------- |
| FI  | Financial Accounting          | 재무회계, 결산, 채권·채무 |
| CO  | Controlling                   | 원가관리, 수익성 분석    |
| MM  | Materials Management          | 자재관리, 구매, 재고    |
| SD  | Sales and Distribution        | 영업, 판매, 출하, 청구  |
| PP  | Production Planning           | 생산계획, 생산관리      |
| QM  | Quality Management            | 품질검사, 품질관리      |
| PM  | Plant Maintenance             | 설비 유지보수         |
| WM  | Warehouse Management          | 창고·재고 위치 관리     |
| EWM | Extended Warehouse Management | 고도화된 창고관리       |
| HCM | Human Capital Management      | 인사, 근태, 급여      |
| PS  | Project System                | 프로젝트 계획, 비용, 일정 |
##  SAP 업무 핵심 용어

| 용어                      | 의미                                         |
| ----------------------- | ------------------------------------------ |
| Master Data             | 마스터 데이터. 자재, 공급업체처럼 반복 사용되는 기준 정보          |
| Transaction Data        | 거래 데이터. 발주, 입고 등 업무 처리 과정에서 생성되는 데이터       |
| Material                | 자재 또는 제품                                   |
| Material Master         | 자재 마스터. 자재코드, 단위, 속성 등                     |
| Business Partner (BP)   | 공급업체·고객 등 거래 상대방의 통합 관리 객체                 |
| Plant                   | 플랜트. 공장, 사업장 등 물류 관리 조직 단위                 |
| Storage Location        | 저장위치. 플랜트 내 재고 관리 위치                       |
| Company Code            | 회사코드. 회계처리를 위한 조직 단위                       |
| Purchasing Organization | 구매조직. 구매 활동을 담당하는 조직                       |
| Purchasing Group        | 구매그룹. 구매 담당자 또는 담당자 그룹                     |
| Document                | 전표·문서. 업무 처리 내역을 기록하는 객체                   |
| Posting                 | 전기. 거래를 시스템에 공식 반영하는 처리                    |
| MRP                     | Material Requirements Planning. 자재소요량계획    |
| BOM                     | Bill of Materials. 자재명세서                   |
| Movement Type           | 이동유형. 입고·출고·이동 등의 재고 이동 구분 코드              |
| T-code                  | Transaction Code. SAP GUI에서 업무 기능을 실행하는 코드 |
